## 1. 项目背景

测试验证组承担 VW-CONNECT 车联网服务门户与 VW-MOBI 移动端应用后台的软件功能验证与回归测试工作。当前测试依赖借用整车或前往试制车间排队占用实车资源，存在三个突出问题：

1. **资源不可控：** 实车借用平均等待 3–5 个工作日，版本回归测试无法按发布节奏开展。
2. **复现困难：** 缺乏固定的台架环境，线上问题的复现率不足 50%，定位周期长。
3. **成本高：** 占用整车进行长时间通电测试，能耗与场地成本高，且存在整车安全管理风险。

为此拟采购 2 台车载电子测试台架（以下简称"车台架"），在实验室内固定部署，用于车机、T-Box、网关等车载电子件的接口联调、软件版本回归与自动化测试。本次采购为低值设备采购，总价控制在人民币 8 万元以内。

## 2. 项目目标

| 编号 | 目标 | 可衡量标准 |
|---|---|---|
| G1 | 建立实验室内可随时使用的测试环境 | 台架可用率 ≥ 95%（工作日 8×5） |
| G2 | 摆脱对实车资源的依赖 | 回归测试实车借用次数下降 ≥ 80% |
| G3 | 提升问题复现与定位效率 | 线上问题台架复现率 ≥ 85% |
| G4 | 支撑自动化测试接入 | 支持通过 CAN 接口与上位机脚本远程控制 |

## 3. 采购范围

### 3.1 范围内（In Scope）

1. 车台架本体供货：2 台，含台架框架、线束、供电与配电模块。
2. 台架集成：按需方提供的电气原理图完成整车网络（CAN/CAN FD/以太网）节点连接与走线。
3. 运输、进场、就位与安装调试。
4. 现场功能验证与出厂测试报告提交。
5. 操作与日常维护培训（不少于 2 小时，覆盖不少于 6 名测试人员）。
6. 随机资料交付：接线图、操作手册、备件清单、合格证。
7. 质保期内的售后响应与维修服务。

### 3.2 范围外（Out of Scope）

1. 车机主机、T-Box、网关、仪表等被测件（ECU）本身，由需方自行提供。
2. 实验室场地改造、强电扩容与网络布线。
3. 自动化测试脚本的开发与测试用例编写。
4. 台架用软件的商业许可证费用（如需，由需方另行采购）。
5. 台架搬迁至本 SOW 指定交付地点以外场所的费用。

## 4. 技术规格要求

以下为强制性最低要求，供应商须逐条应答"满足／不满足"，不满足项须说明替代方案。

| 编号 | 项目 | 最低要求 |
|---|---|---|
| T-01 | 台架结构 | 铝型材框架，带脚轮与锁定装置，可单人移动；台面尺寸不小于 1200 × 700 mm |
| T-02 | 承载能力 | 台面静载不低于 80 kg，安装面支持自由开孔与模块加装 |
| T-03 | 供电系统 | 输入 AC 220 V；输出可调直流 9–16 V，额定电流不低于 30 A，具备过压、过流与短路保护 |
| T-04 | 点火模拟 | 支持 OFF / ACC / ON / START 四档模拟，可通过面板与远程指令切换 |
| T-05 | 总线接口 | 至少 2 路 CAN / CAN FD、1 路车载以太网（100BASE-T1）、2 路 LIN，接口引至面板端子 |
| T-06 | 信号调理 | 提供不少于 8 路数字量输入输出与 4 路模拟量通道，用于开关、传感器信号模拟 |
| T-07 | 远程控制 | 支持上位机通过 USB 或以太网下发电源通断、点火档位切换指令，提供接口文档 |
| T-08 | 线束 | 按需方原理图定制整车线束，接插件与整车一致，标签清晰、可维护 |
| T-09 | 安全 | 具备急停按钮、漏电保护与接地；符合国家电气安全相关标准 |
| T-10 | 一致性 | 2 台台架的配置、走线与接口定义完全一致，可互换使用 |

> 需方将在合同签订后 5 个工作日内向供应商提供整车电气原理图与接插件清单（脱敏版本），供应商据此完成线束定制。

## 7. 验收标准

### 7.1 到货验收

1. 数量、型号、外观与合同一致，无运输损伤。
2. 随机资料齐全（D3、D5、D6、D7）。

### 7.2 功能验收（逐台执行，两台均须通过）

| 编号 | 验收项 | 合格判据 |
|---|---|---|
| A-01 | 供电与保护 | 输出电压在 9–16 V 范围内可调，精度 ±0.2 V；触发过流保护后可正常复位 |
| A-02 | 点火档位 | 四档切换正确，被测件上下电时序符合原理图要求 |
| A-03 | 总线通信 | CAN / CAN FD / 以太网 / LIN 各路均可正常收发报文，连续通信 2 小时无丢帧 |
| A-04 | 远程控制 | 上位机脚本可完成不少于 20 次连续上下电循环，动作成功率 100% |
| A-05 | 老化测试 | 连续通电运行 8 小时无异常断电、无异常温升 |
| A-06 | 一致性 | 两台台架互换被测件后功能表现一致 |
| A-07 | 安全 | 急停按钮有效，接地电阻符合要求 |

验收由需方测试验证组与实验室管理员共同执行，出具《验收报告》并双方签字。发现不合格项的，供应商须在 5 个工作日内整改并重新验收；两次整改仍不合格的，需方有权退货并要求全额退款。

## 8. 商务要求

1. **报价口径：** 按台报价（含税、含运输、含安装调试与培训），另附备件与易损件单价表。**两台总价不得超过人民币 80,000 元（含 13% 增值税）。**
2. **价格有效期：** 自报价提交之日起不少于 90 天。
3. **付款条件：**

| 节点 | 比例 | 条件 |
|---|---|---|
| 到货并完成安装调试（M3） | 30% | 凭到货验收记录 |
| 验收报告签署（M5） | 60% | 凭双方签字的《验收报告》与全额发票 |
| 质保期满 | 10% | 质保期内无重大质量问题 |

4. 结算币种为人民币，付款方式为电汇，账期为收到合规发票后 60 天。
5. 供应商须为一般纳税人，能够开具 13% 增值税专用发票。

## 9. 质保与售后

1. 质保期为验收合格之日起 **12 个月**，覆盖非人为损坏的全部部件（易损件除外）。
2. 故障响应：接到报修后 **4 小时内**电话响应；需现场处理的，**2 个工作日内**到场。
3. 质保期内同一部件累计故障 3 次以上的，供应商须免费更换该部件。
4. 质保期满后，供应商应继续提供不少于 3 年的备件供应与有偿维修服务，备件价格不高于本次报价的备件清单价格上浮 10%。
