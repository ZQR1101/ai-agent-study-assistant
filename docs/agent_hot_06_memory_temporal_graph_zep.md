# 时间感知记忆与知识图谱

tags: memory, knowledge-graph, zep, temporal, graphiti, 2026

## 摘要

传统 RAG 更像静态文档检索：文档写入后，查询时取相似片段。长期运行的 agent 还需要动态记忆：从持续对话、业务事件和工具结果中提炼事实，并理解这些事实的时间顺序、变更和冲突。

## 为什么需要时间维度

用户偏好、项目状态、权限、价格、任务进度都会变化。如果记忆系统只存“最新相似文本”，就容易把旧事实当成当前事实。时间感知图谱会把实体、关系、事件、有效时间和来源一起保存，帮助 agent 回答“现在是什么状态”“之前为什么这么做”“哪个事实更新”。

## 图谱记忆的优势

知识图谱适合跨会话合并碎片信息。例如一次会议提到客户 A 的预算，另一次邮件更新采购窗口，第三次聊天说明决策人变化。图谱能把这些事实连接到同一实体上，而不是只返回若干相似段落。

## 与向量检索的关系

图谱记忆不替代向量检索。常见组合是：向量搜索召回候选内容，图谱用于实体消歧、时间排序、关系推理和冲突处理。RAG 负责“找相关材料”，记忆图谱负责“维护世界状态”。

## Agent 设计启示

长期 agent 应把“记忆写入”当成独立组件评测：是否过度记忆、是否漏记、是否能更新旧事实、是否保留来源、是否能删除敏感记忆。
