# 百度 OCR 与文档型 Agent

tags: baidu-ocr, ocr, document-agent, multimodal-rag, chinese-docs, 2026

## 摘要

文档型 agent 经常需要处理扫描件、票据、合同、证照、物流单、医疗单据和截图。OCR 是把非结构化图像转成可检索文本和字段的入口层。百度智能云 OCR 提供多场景、多语种、高精度文字检测与识别服务，覆盖金融、财税、政务、保险、医疗、物流、交通、教育等场景。

## Agent 集成方式

最小流程是：上传图片或 PDF 页面，调用 OCR，得到文本和位置信息，做字段结构化，再写入 RAG 索引或业务数据库。对于票据、证照、合同等强结构场景，应优先使用专门 OCR 接口或自定义模板，而不是只用通用文字识别。

## 与 RAG 的关系

OCR 输出不应直接作为唯一事实。推荐保留三层数据：原图或文件引用、OCR 原始输出、清洗后的结构化字段。RAG 检索时返回清洗字段，同时可追溯到原图坐标，便于人工核验。

## 私有化与离线

高敏感文档可考虑私有化部署或离线 SDK。百度 OCR 文档提到本地服务器部署、移动端/设备端离线识别和多平台支持。对医疗、金融、政务等领域，数据出域和留存策略要先于模型选择。
